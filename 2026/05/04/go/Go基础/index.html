定义变量

Go 当中的定义变量有以下几种方式：

全局变量和局部变量

  • 全局变量：函数外声明
  • 局部变量：函数内声明（只能在当前函数内使用）
  • 局部变量中未使用的变量会直接报错
  • 全局变量中未使用的变量不会报错，只有警告

多个变量同时赋值

Go 语言中也可以对多个变量同时赋值

常量定义

常量定义特性：

  1. 定义的时候就要赋值
  2. 后续无法修改

命名规范

变量、方法和属性需要跨包访问时，使用首字母大写才能被访问

fmt.Println()函数始终会在两个参数之间加上空格，并在末尾补上换行符

基本数据类型

Go 语言中的基本数据类型主要有5个：

  1. 整数型
  2. 浮点型
  3. 复数
  4. 布尔
  5. 字符串

整数型

GO 里面的整数形有很多种：

  1. 默认的数字定义类型是 int 类型
  2. 带个 u 就是无符号，只能存正整数
  3. 后面的数字就是 2 进制的位数
  4. uint8 还有一个别名 byte，一个字节=8 个 bit 位
  5. int 类型的大小取决于所使用的平台

浮点型

Go 语言支持两种浮点型数：float32 和 float64

  1. float32 的浮点数的最大范围约为 3.4e38，可以使用常量定义：math.MaxFloat32
  2. float64 的浮点数的最大范围约为 1.8e308，可以使用一个常量定义：math.MaxFloat64

如果没有显式声明，则默认是 float64

字符型

比较重要的两个类型是 byte（单字节字符）和 rune（多字节字符）

  1. 在 Go 中，字符的本质是一个整数，直接输出时，是该字符对应的 UTF-8 编码的码值
  2. 可以直接给某个变量赋一个数字，然后按格式化输出时 %c，会输出该数字对应的 unicode 字符
  3. 字符类型是可以进行运算的，相当于一个整数，因为它都对应有 Unicode 码
  4. 在 GO 源码中，byte 就是 uint8，rune 就是 int32

字符串类型

字符串使用的是双引号””，而字符类型用的是单引号’’

转义字符

这部分都差不多

多行字符串

多行字符串使用 `` 包裹即可，里面的转义字符不生效

布尔类型

布尔类型（bool）只有true和flase两个类型

  1. 布尔类型变量默认false
  2. Go 语言中不允许将整型强制转换成布尔类型
  3. 布尔类型不参与数值运算，也不能转换成其他类型

零值问题

Go 语言里面的变量有默认值

  • 字符串默认””
  • 布尔类型默认false
  • 整数类型默认0

数组

Go 里面的数组和其他语言的差不多

  1. 数组里面的元素必须是同一类型
  2. 声明数组时，必须指定大小

切片

切片其实就是数组 Plus，叫做 slice，其相对于数组更灵活，并且长度可变

除了基本数据类型，其他数据类型定义了但是不赋值，那么就是nil

make函数

我们可以通过make函数创建知道长度、指定容量的切片

切片名字由来

切片的意思其实就是数组切出来的

切片排序

map

Go 语言里面的 map 是一种内置的数据结构，也就是键值对

map 里面的 key 必须是基本数据类型，value 可以是任何类型

同时，map 的使用一定要初始化

判断语句

Go 里面有if、else if和else，不需要加括号

需要注意，Go 允许在条件判断前使用一个简短的判断语句

switch语句

基础用法：

  1. 自动 break
  2. 可以同时匹配多个值
  3. 匹配的时候是从上往下，匹配到一个执行完之后就会退出

Go 里面的 switch 可以省略表达式，每一个 case 都是一个布尔条件判断

同时，switch 语句也支持初始化语句，作用域只在 switch 里面

还可以用来判断一个变量的类型

还有一个fallthrough 关键字，作用是强制穿透

注意：fallthrough不会判断是否成立，执行到了之后会立即执行下一个 case 语句
