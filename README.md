# Hiiii113 个人博客

这是一个基于 **Hexo** 构建的个人博客仓库，使用 **Butterfly** 主题，部署于 GitHub Pages（<https://hiiii113.github.io/>）。

## 简介

本博客用于记录个人的学习笔记与知识分享，主要内容包括：

- **算法学习**：StarryCoding 算法课程系列笔记，涵盖数论、图论、动态规划、并查集、最短路、最小生成树等算法专题。
- **数据库**：Redis 入门学习笔记。

## 目录结构

```text
repo-1/
├── index.html          # 首页
├── archives/           # 归档页面
├── posts/              # 文章页面
├── tags/               # 标签页面
├── categories/         # 分类页面
├── css/                # 样式文件
├── js/                 # 脚本文件
├── img/                # 图片资源
├── atom.xml            # Atom 订阅
├── search.xml          # 站内搜索数据
└── sitemap.xml         # 站点地图
```

## 技术栈

- **框架**：[Hexo](https://hexo.io) 8.1.1
- **主题**：[Butterfly](https://github.com/jerryc127/hexo-theme-butterfly) 5.5.4
- **部署**：GitHub Pages

## 使用说明

1. 克隆本仓库到本地。
2. 安装依赖：`npm install`
3. 本地预览：`hexo server`
4. 生成静态站点：`hexo generate`
5. 部署到 GitHub Pages：`hexo deploy`
