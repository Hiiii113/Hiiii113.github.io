Redis

一、Redis 概述

Redis 的全称是 Remote dictionary server，是一个开源的基于内存的数据存储系统，可以用作数据库、缓存、消息队列等各种场景，Redis 也是目前最热门的 NoSQL 数据库之一

相较于传统的数据库（MySQL）来说，Redis 使用的是内存读写而非磁盘 IO，这会让数据查询的速度大大加快

1. Redis 的数据类型

Redis 包含以下几种基本数据类型

  • 字符串（String）

  • 列表（List）

  • 集合（Set）

  • 有序集合（SortedSet）

  • 哈希（Hash）

和以下几种高级数据类型：

  • 消息队列（Stream）

  • 地理空间（Geospatial）

  • HyperLogLog

  • 位图（Bitmap）

  • 位域（Bitfield）

2. Redis 的使用方式

Redis 的使用方式有以下几种：

  • CLI（Command Line Interface）
    • 即通过命令行工具使用
  • API（Application Programming Interface）
    • 即通过 Java、Python 等语言进行使用 Redis
  • GUI（Graphical User Interface）
    • 即通过图形化界面，比如 Redisinsight 使用 Redis

3. 优点

总得来说，Redis 的优势有以下几点：

  • 性能极高
  • 数据类型丰富，单键值对最大支持512M大小的数据
  • 简单易用，支持所有主流编程语言
  • 支持数据持久化、主从复制、哨兵模式等高可用 特性

二、安装配置

对于 Mac 或者 Linux 系统来说，安装 Redis 十分简单，只需要一行命令

但是对于 Windows 系统来说只有以下几种方法：

  • 使用 Docker 安装镜像并运行
  • 使用 WSL2 安装 Linux 发行版并安装运行
  • 使用第三方提供的 windows 版本
