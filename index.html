定义变量

Go 当中的定义变量有以下几种方式：

全局变量和局部变量

  • 全局变量：函数外声明
  • 局部变量：函数内声明（只能在当前函数内使用）
  • 局部变量中未使用的变量会直接报错
  • 全局变量中未使用的变量不会报错，只有警告

基本数据类型

Go 语言中的基本数据类型主要有5个：

  1. 整数型
  2. 浮点型
  3. 复数
  4. 布尔
  5. 字符串

整数型

GO 里面的整数形有很多种：

  1. 默认的数字定义类型是 int 类型
  2. 带个 u 就是无符号，只能存正整数
  3. 后面的数字就是 2 进制的位数
  4. uint8 还有一个别名 byte，一个字节=8 个 bit 位
  5. int 类型的大小取决于所使用的平台

浮点型

Go 语言支持两种浮点型数：float32 和 float64

  1. float32 的浮点数的最大范围约为 3.4e38，可以使用常量定义：math.MaxFloat32
  2. float64 的浮点数的最大范围约为 1.8e308，可以使用一个常量定义：math.MaxFloat64

如果没有显式声明，则默认是 float64

字符型

比较重要的两个类型是 byte（单字节字符）和 rune（多字节字符）

  1. 在 Go 中，字符的本质是一个整数，直接输出时，是该字符对应的 UTF-8 编码的码值
  2. 可以直接给某个变量赋一个数字，然后按格式化输出时 %c，会输出该数字对应的 unicode 字符
  3. 字符类型是可以进行运算的，相当于一个整数，因为它都对应有 Unicode 码
  4. 在 GO 源码中，byte 就是 uint8，rune 就是 int32

字符串类型

字符串使用的是双引号””，而字符类型用的是单引号’’

转义字符

这部分都差不多

多行字符串

多行字符串使用 `` 包裹即可，里面的转义字符不生效

布尔类型

布尔类型（bool）只有true和flase两个类型

  1. 布尔类型变量默认false
  2. Go 语言中不允许将整型强制转换成布尔类型
  3. 布尔类型不参与数值运算，也不能转换成其他类型

单元测试

Go 语言中自带有一个轻量级的测试框架 testing 和自带的 go test 命令来实现单元测试和性能测试，testing 框架和其他语言的测试框架相似，可以基于这个框架写针对相应函数的测试用例，也可以基于该框架写相应的压力测试用例。通过单元测试，可以解决：

  1. 确保每个函数是可运行，并且运行结果是正确的
  2. 确保写出来的代码性能是好的
  3. 单元测试能及时的发现程序设计或实现的逻辑错误，使问题暴露，便于问题的定位解决，而性能测试的重点在于发现程序设计上的一些问题，让程序能够在高并发的情况下还能保持稳定

Go 语言推荐测试文件和源代码文件放在一块，测试文件以 _test.go 结尾

需要注意的是

  1. 测试用例文件名必须以_test.go 结尾
  2. 测试用例函数必须以 Test 开头，一般来说就是 Test+被测试的函数名

  • 当我们新建了一个int类型的数组的时候，我们想要输出一个元素的值，输出了0

    • 这是因为String数组当中的每一个元素都是一个管理者，而非String本身

    • 没有给String数组中元素分配东西的时候，没有指向任何东西，所以使用length()会报错

    • 所以我们定义了一个String类型的变量并初始化为null的时候，使用length()会报错

用一句话来说就是：对象数组中的每个元素都是对象的管理者而非对象本身

子类和父类

如何创建

我们如果需要创建两个类，分别是CD和DVD，存储一些信息的时候，很容易发现这两者的代码有高度重复性，为了解决这个问题，Java拥有了子类和父类这两个概念

父类Item直接使用普通的类定义即可

子类的定义只需要在定义后面加上extends 父类名称即可

继承

在子类定义之后，子类就继承了父类的东西，此外子类还可以自己添加新的东西到子类当中

  • 所谓的继承就是拥有了父类的成员变量和成员函数

    • 但是需要注意的是无法继承父类中用private关键字修饰的成员变量或者函数

    • 如果使用protected，子类和同包可访问

对于子类自己定义的接口或者变量，子类自行初始化

对于继承来的父类的变量，子类可以通过super()函数传入接收到的值并利用父类中的构造方法进行初始化

顺序

子类的初始化一定遵循：

  • 先进行父类变量的初始化和构造函数

  • 在进行子类变量的初始化和构造函数

子类和父类的关系

  • 子类可以继承得到父类的所有东西

    • 但是private的东西子类不能直接使用，需要使用super()函数调用父类中对应的构造函数

  • 子类中如果有和父类中同名的变量，则在子类里面操作时，默认操作的是子类自己的那个变量

    • 如果子类和父类都有title这个变量

    • 子类中的this.title指的是子类自己的，父类中的this.title指的是父类中的

  • 同样的，如果子类和父类都拥有同名函数

    • 默认会调用子类中的函数

    • 需要使用super.函数名来调用父类中的函数

多态变量

首先需要明确的是，在Java当中

  • 类定义了类型

  • 子类定义了子类型

  • 子类的对象可以被当作父类的对象来使用

    • 赋值给父类的变量

    • 传递给需要父类对象的函数

    • 放进存放父类对象的容器里

也就是说

  • Java的对象变量是多态的，他们能保存不止一种类型的对象

  • 它们可以保存声明类型的对象，也可以保存声明类型的子类的对象

  • 当把子类的对象赋给父类的变量的时候，就发生了向上造型

表达概念而无法构造出实体的类

  • 带有abstract关键字的函数或者类

    • 我们拿这个父类变量（实际上是子类对象）调用这个函数的时候，编译器只会检查父类抛出的异常是否解决，而完全不知道这个子类对象还会抛出更多的异常，这样就可能导致异常没有被捕捉到

    • 当然我们可以在子类新建一个新的、父类没有的函数的时候，声明可能抛出的新的异常

  • 第二点

    • 在子类的构造函数调用的时候，必定会调用到父类的构造函数

    • 这个时候假如说父类的构造函数抛出了一个异常，而子类的构造函数又声明这个异常，这就可能导致这个异常无法被捕捉

    • 所以必须声明父类构造函数中声明的所有异常，当然也可以声明新的异常

正则表达式

﻿# 正则表达式

正则表达式是一种用于匹配所需字符串的计算机常用方法，是一种用特殊符号描述文本规则的工具

简单说：用一串特殊符号来定义”我要匹配什么样的字符串”

相关匹配规则如下：

  • 限定符
  • 或运算符
  • 元字符
  • 字符类
  • 贪婪与懒惰匹配

1. 限定符

  • ? 限定符是限定符中常用的一种，表示它前面的字符可以出现 1 次或 0 次

  • * 限定符的作用是：前面的字符可以出现 0 次或无数次

  • + 限定符的作用是：前面的字符可以出现 1 次或无穷次，也就是对 * 的结果筛选出了至少出现了 1 次的情况

  • {...} 限定符的作用：前面的字符可以出现{}中数字的次数，比如 /ab{3}c 就会匹配到 abbbc

还有更加高级的用法：

  • /ab{2,6}c 会匹配到 b 的个数是 2-6 之间的
  • /ab{2,}c 会匹配到 b 的个数是 2 个以上的

上面对于限定符的例子都是针对一个字符使用的，但是限定符还可以对多个字符使用，只需要给需要的字符套上括号即可

2. 或运算符

正则表达式中的或运算符是用于匹配时表达a or b的逻辑而出现的

比如：

这里就表示了需要匹配 a 并且后面匹配 (dog|cat)

注意必须要这个括号 ()，否则就变成了 a dog|cat ：要么是 a dog 要么是 cat

3. 元字符

元字符是正则表达式自带的一些定义好的匹配类型，不需要手动 [0-9] 来匹配数字

如下：

  • /d 数字字符
  • /w 单词字符（所有英文字母 + 数字 + 下划线 _）
  • /s 空白字符（Tab + 换行符）
  • /D 非数字字符
  • /W 非单词字符
  • /S 非空白字符
  • . 所有字符（不包含 Tab）

除此以外，还有 ^ 和 $，他们分别表示匹配行首和行尾

比如：/^a 表示匹配处于行首的 a，/a$ 表示匹配处于行尾的 a

4. 字符类

字符类表示的是：匹配到的结果中，用到的字符只能来自于这里面

例如：[abc]

也可以指定范围

比如 [a-z] 代表小写字母，[a-zA-Z] 代表所有字母，[a-zA-Z0-9] 代表所有字母和数字

其中我们可以使用 ^ 表示除了方括号内都可以匹配上

比如：[^0-9] 代表了所有非数字

5. 贪婪与懒惰匹配

这是一串 html 标签：<span<b>this is an text</b>></span>

当我们尝试使用正则表达式匹配的时候，可能会使用：<.+> 来处理

但是我们发现：这个正则表达式把所有的字段全部匹配了

这是因为：. 代表任意字符，而 + 会匹配尽可能多的字符，导致了这样的结果

解决方式也很简单：改成 <.+?> 即可将默认的贪婪匹配变成懒惰匹配

6. 工具网站

在线检测正则表达式匹配网站： regex101: build, test, and debug regex

﻿# 封装 axios

axios 的请求已经很完善了，但是我们还可以根据项目的实际情况进行个人的封装
封装主要需要实现的功能如下：

  1. 实现请求拦截
  2. 实现响应拦截
  3. 常见错误信息处理
  4. 请求头设置
  5. api 集中式管理

1. Axios 中文官网

有任何疑问可以参考该文档：Axios中文文档 | Axios中文网

2. 安装axios

在项目文件夹下使用终端运行npm install axios以安装

3. 封装

在适合的位置新建一个 js 文件，然后在里面封装 axios 请求

首先，axios请求可以使用axios({})或者axios.post()的方式发送，但是，axios还存在其他的方法可以发送请求

我们可以创建一个 axios 的实例，并且使用相关的方法

3.1 导入

首先，使用import语句导入axios

3.2 创建应用实例

使用 axios.create({}) 方法创建一个实例
其中两个参数的解释：

  • baseURL：请求的基础 url，会和具体的方法路径拼接而成具体的地址
  • timeout：超时时间，设定成10000就是10秒钟未成功视为超时

3.3 设置请求拦截

请求拦截的意思就是：在请求发出之前我们可能需要对请求头进行处理，例如附加一些 token 之类的，这个时候就需要使用请求拦截器把请求拦截下来，处理业务逻辑

3.4 设置响应拦截

axios的返回结果默认携带很多东西，所以设置一个响应拦截可以先对结果进行处理，再将结果返回给调用者

4. 使用

现在，就成功的封装了axios，只需要在其他JS文件或者<script>块使用import语句导入所需要的post或者get即可
